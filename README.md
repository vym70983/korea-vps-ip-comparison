## 常见问题

### 韩国VPS到国内的延迟大概什么水平？

比美西节点低一截，这是韩国机房的天然优势。但具体到多少毫秒，取决于线路而不是机房位置——同样是首尔机房，CN2直连、三网优化和国际线路的差距不小。别只看宣传页，下单前用商家的测试IP和Looking Glass实测一遍。

### 原生IP、家宽IP、双ISP分别指什么？

这三个词描述的是三个不同维度：原生说的是IP归属地与机房所在地一致，广播IP则相反，归属地对不上；家宽（住宅）说的是IP登记为宽带家庭用户，而非数据中心；双ISP一般指IP在主流归属数据库中被判定为ISP/住宅属性，风控眼里更接近真实家庭用户。三者可以叠加，选购时逐项确认，看到“原生”两个字不代表同时带住宅属性。
